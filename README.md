# Uranium-Programming-Language
450.000+ lines of C++ programming language running on a Uranium Virtual Machine with JIT Engine and GC.

# Compiling
* CMD
```cmd
   cd Uranium
   mkdir bin && cd bin
   cmake .. && cmake --build . --config Release
```
* bash
```bash
   cd Uranium
   mkdir bin && cd bin
   cmake .. && cmake --build . --config Release
```
------------
Uranium now works almost seamlessly with Linux and macOS
(If there is an error, please do not hesitate to let me know.)
